## First Run Guide

Prerequisites: a supported desktop environment, a repository checkout or release build, and a workspace where time records can be stored.

1. Download or clone Time Statement GitHub files and review the Time Statement documentation before first use.  
2. Open Time Statement app and create the projects, clients, or work categories needed for reporting.  
3. Start Time Statement time tracking when work begins, then add notes that explain the task clearly.  
4. Review the timesheet statement at the end of the day and adjust incomplete entries before sharing.  
5. Export Time Statement reports when payroll, billing, or project review requires a polished summary.
